# Yatee Steel Structures - PEB Website

Official website for **Yatee Steel Structures**, manufacturers and turnkey solutions providers of Pre-Engineered Steel Buildings (PEB), Heavy Structural Steel Fabrication, Roofing, and Cladding Systems.

## Tech Stack
- **Framework**: Next.js (App Router, Turbopack)
- **Styling**: Tailwind CSS
- **Icons**: Lucide React
- **Animations**: Framer Motion, Canvas Confetti

## Deployment (Vercel)
- **Root Directory**: `website`
- **Framework Preset**: Next.js
- **Build Command**: `next build`
- **Output Directory**: `.next`
